# timbre-mapping-for-shakuhachi

尺八の音色をVAE（Variational Autoencoder）を用いて潜在空間に表現し、可視化するための研究用プログラムです。
尺八演奏音声から音響特徴量を抽出し、音色の特徴を潜在空間に学習させることで、異なる奏法による音色の違いや変化を視覚的に捉えることを目的としています。
また、学習済みモデルを利用し、マイクから入力された音声をリアルタイムに解析して、2次元の潜在空間上に表示する機能も実装しています。

## 1. 主な機能

- **音声のトリミング**：WAVファイルから無音区間を除去し、音声区間ごとに分割
- **データセット作成**：音声のセグメント分割、ピッチ・RMS正規化、メルスペクトログラム等の特徴量抽出
- **音色特徴の学習**：VAEによる潜在表現の学習と、調波・ノイズ成分を用いたスペクトログラム再構成
- **潜在空間の可視化**：PCAによる潜在表現の2次元可視化
- **リアルタイム可視化**：マイク入力音声を学習済みエンコーダで解析し、潜在空間上に逐次プロット

## 5. 実行方法

### 5.1 音声のトリミング

`trim.py` 内の入力フォルダ（`wav_dir`）と出力フォルダ（`seg_wav_dir`）を設定します。

```bash
python trim.py
```

各WAVファイルから、無音区間を基準に音声を分割します。

主な設定は以下の通りです。

- サンプリング周波数：44,100 Hz
- 無音区間判定：`top_db=20`
- 保存対象の最短区間：1.2秒
- 出力形式：WAV（16-bit PCM、モノラル）

### 5.2 学習用データセットの作成

`mk_dataset.py` 内の入力フォルダ（`root`）と出力先（`save_path`）を設定します。

```bash
python mk_dataset.py
```

主な処理内容は以下の通りです。

- 1.2秒のセグメントを0.4秒間隔で抽出
- pYINによる基本周波数の推定
- 基準周波数530 Hzへのピッチ正規化
- RMSによる音量正規化
- 256バンドの対数メルスペクトログラム生成
- 基本周波数・RMSを条件特徴量として保存

入力音声のファイル名の先頭部分（`_` より前）を奏法ラベルとして利用します。

生成した特徴量とラベルは、PKL形式で保存されます。

### 5.3 VAEの学習

`training/config.py` に、学習データと出力ファイルのパスを設定します。

- `CACHE_PKL`：学習用PKLファイル
- `BEST_PATH`：学習済みモデルの保存先
- `PCA_PATH`：PCAモデルの保存先
- `NPZ_PATH`：潜在空間データの保存先

リポジトリ直下から以下を実行します。

```bash
python training/main.py
```

学習では、メルスペクトログラムを入力とするVAEを使用します。

エンコーダは畳み込みニューラルネットワークで構成され、16次元の潜在表現を学習します。デコーダは基本周波数・RMSを条件として、調波成分とノイズ成分からメルスペクトログラムを再構成します。

再構成誤差にはL1損失、潜在分布の正則化にはKLダイバージェンスを使用します。

学習中は潜在表現をPCAによって2次元に変換し、奏法ラベルごとに可視化します。

検証損失が改善した際に、学習済みモデルと可視化に必要なデータを保存します。

### 6.4 リアルタイム音色可視化

`real_time_plot.py` に、学習済みモデル、PCAモデル、潜在空間データの読み込み先を設定します。

```bash
python real_time_plot.py
```

起動するとGUIが表示されます。

- **Start**：マイク入力音声の解析・プロットを開始
- **Stop**：プロットの更新を停止
- **Quit**：アプリケーションを終了

入力音声に対して学習時と同様のピッチ・音量正規化を行い、エンコーダから抽出した潜在表現をPCAで2次元に変換します。

学習データの潜在空間上に、新しく入力された音声の位置を逐次表示します。

## 6. データと実行上の注意

本リポジトリは研究用プログラムのソースコードを公開するものです。

著作権やファイル容量等を考慮し、学習に使用した音声ファイル、生成したデータセット、学習済みモデル等は原則として含めていません。

学習を再現するには、別途WAV音声を用意する必要があります。また、リアルタイム可視化を実行するには、対応する学習済みモデル、PCAモデル、潜在空間データが必要です。

各スクリプトの入力・出力パスは、実行環境に合わせて設定してください。

なお、本コードは研究過程で作成した実験用実装であり、異なる環境での動作やリアルタイム処理性能を保証するものではありません。

## 7. 研究の位置づけ

本プログラムは、尺八演奏の音色特徴を潜在空間上に表現し、演奏中の音色の違いや時間的変化を分析するために開発したものです。

音色の違いを視覚的に捉えるための表現学習と、実際の演奏音声を用いたリアルタイム可視化の実現を目指しています。
